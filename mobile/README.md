# SmartStock AI - Flutter client

GetX + Dio client for Android, iOS, web, Windows, macOS and Linux.

```bash
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8000
flutter analyze && flutter test
LIVE_API_URL=http://localhost:8000 flutter test test/live   # needs a running, seeded backend
```

See the repository [README](../README.md) and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md#flutter-client).
